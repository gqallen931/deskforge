# 核心模块操作状态加固

## 背景

React 业务模块已完成迁移，但部分异步操作仍缺少加载、失败和重复提交保护；归档、删除、数据导入与恢复等操作也需要明确风险边界。

## 本次实现

- 任务中心：首次加载、空结果、错误重试、统一异步操作状态、中文任务状态；归档与永久删除分别提示影响范围。
- 项目中心：加载和错误状态、创建与分配防重复提交、只展示尚未加入当前项目的任务；移出任务与归档项目增加确认，移除全局 DOM 查询。
- 文件索引：添加、打开、移除失败均可见；移除前说明只删除 Deskforge 索引，不删除原文件。
- 通知提醒：并行加载失败处理、中文时间和状态、全部已读可用性控制、创建与删除防重复提交。
- 设置中心：首次读取失败可重试；保存、更新、备份、导入、恢复、密码修改均统一显示处理中和错误状态。
- 数据安全：导入与恢复前明确提示会影响当前数据；服务端仍会先创建 `pre-import` 或 `pre-restore` 安全备份；历史备份恢复和永久删除均需单独确认。
- 自动化界面验证：CDP 操作超时由 10 秒调整为 30 秒，并在超时或连接失败时正确释放连接，以兼容较慢的 Windows 环境。

## 保持不变

- A-UI iframe 视觉壳和现有 CSS 类名保持不变。
- 所有数据仍经 Preload 安全桥进入 Main/SQLite，不在 Renderer 直接访问文件或数据库。
- AI 建议和消息模块继续显示“正在开发中”。
