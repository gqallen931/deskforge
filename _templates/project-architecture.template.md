## 四、API 通信链路

### 4.1 架构概述

```
┌─────────────────────────────────────────────────────────────────┐
│                        请求路由决策                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  开发模式                                                       │
│  ┌─────────────┐   /api/*    ┌──────────┐   /api/*   ┌──────┐  │
│  │ 前端 Client │ ──────────→ │ 代理层   │ ─────────→ │ 后端  │  │
│  └─────────────┘             └──────────┘            └──────┘  │
│                                                                 │
│  生产模式                                                       │
│  ┌─────────────┐   /api/*    ┌────────────────────┐  ┌──────┐  │
│  │ 前端 Client │ ──────────→ │ 请求拦截/重写层    │─→ │ 后端  │  │
│  └─────────────┘             └────────────────────┘  └──────┘  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 4.2 前端 API 层

| 文件 | 用途 |
|------|------|
| `client.ts` | HTTP 客户端：`fetchJson`、`isBackendReady` |
| `endpoints.ts` | API 端点定义 |
| `sse.ts` | SSE 流式通信（如适用） |

### 4.3 后端端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/health` | GET | 健康检查 |
| `/api/xxx` | GET/POST | 业务端点 |

### 4.4 降级策略（如适用）

1. `isBackendReady()` 探测后端
2. `withBackend()` 优先真实后端，失败降级到 mock
3. 后端启动失败时自动降级为 Mock Server
